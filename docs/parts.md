## 手持ち・現物確認が必要なもの

| 項目 | 必要な確認 |
|---|---|
| 電池箱・単3電池 | 2本/3本のどちらか、極性、電源スイッチ、基板電源端子への接続方法 |
| USB-Cデータケーブル、USB電源 | 書き込み用と待機部屋の常時給電用 |
| ボタン外付けプルアップ | GPIO0/1に10kΩ程度×2を推奨。1kΩ10本直列でも10kΩだが配線が増える。追加購入確定ではない |
| LCDケーブルの変換 | SH1.0側の向き、端子表示、2.54mm接続の可否 |
| アクリル板・アセテートテープ | 最初はテープで仮固定する方針。入手状況は未記載 |
| M2ネジ・ナット | スペーサーとは別。厚さと配置を決めてから長さを選ぶ |
| はんだ・工具・テスター | 手持ちを確認。ドリルとストリッパーは購入不要という最終判断 |
