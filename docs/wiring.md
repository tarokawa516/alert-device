# 回路・配線図（ブレッドボード試作版）

この図はネット接続を示す初期案です。部品を載せる穴位置の実体図・製造用CADではありません。
基板リビジョン、ソケットの向き、LCDケーブルの自由端を現物確認してから実配線を確定します。
GPIOの一覧は [gpio.md](gpio.md) です。

## 弘文さん側

```text
単3電池箱＋ ───── 10942の指定電池入力（基板印字・メーカー図で確認）
単3電池箱－ ──┬─ 10942 GND
              └─ GND共通バス

10942 3V3 ────── ePaper 3V3（Pico互換端子 36）
GND共通バス ──── ePaper GND（例：Pico互換端子 13）

ESP32             Pico-ePaper-2.66側
GPIO4  ───────── GP10 / CLK  [物理14]
GPIO6  ───────── GP11 / DIN  [物理15]
GPIO7  ───────── GP9  / CS   [物理12]
GPIO10 ───────── GP8  / DC   [物理11]
GPIO3  ───────── GP12 / RST  [物理16]
GPIO5  ───────── GP13 / BUSY [物理17]

3V3 ──[10kΩ推奨]──┬── GPIO0
                  └──[飲んだ NOボタン]── GND
3V3 ──[10kΩ推奨]──┬── GPIO1
                  └──[呼出 NOボタン]──── GND

GPIO20 ──[1kΩ]── LEDアノード(A) ─>|─ カソード(K) ── GND
```

ソフトは内蔵プルアップを使いますが、最終組み立てでは外付けプルアップも検討します。
図の10kΩは最終カートに別品として含まれません。追加調達または手持ちで用意します。
4本足タクトスイッチの同一側の足は内部接続されている場合があります。
押す前は開放、押すと導通する一対をテスターで確認してください。

電池をESP32の3V3端子やePaperへ直接入れません。
USBと電池の同時接続は現物基板の電源切替仕様を確認するまで避け、書き込み時は電池を外します。

## 待機部屋側

```text
USB電源 ── USB-C ── KOHACRAFT 10646

10646 3V3 ───────── LCD VCC
10646 GND ──┬────── LCD GND
            └────── 通知基板GND

GPIO4  ──────────── LCD_CLK
GPIO6  ──────────── LCD_DIN (MOSI)
GPIO7  ──────────── LCD_CS
GPIO10 ──────────── LCD_DC
GPIO3  ──┬───────── LCD_RST
         └───────── TP_RST
GPIO5  ──────────── LCD_BL
GPIO0  ──────────── TP_SDA
GPIO1  ──────────── TP_SCL
                    TP_IRQ → 未接続・絶縁

GPIO21 ──┬──[1kΩ]── LED1(A) ─>|─(K)── GND
         ├──[1kΩ]── LED2(A) ─>|─(K)── GND
         └──[1kΩ]── LED3(A) ─>|─(K)── GND

GPIO20 ─────[1kΩ]── PKM13EPYH4000-A0 ── GND
```

LED3個は各抵抗を含む3枝を並列にします。抵抗1本を3個で共有しません。
Vf=2.0Vの概算で1枝約1.3mA、合計約3.9mAから試します。
1kΩ2本並列なら500Ωですが、これは明るさ確認後の調整案であり初期配線には不要です。

サウンダーは発振回路のない圧電素子です。DCのHIGH固定では連続音は出ないため、
LEDCで4kHzを生成します。今回はメーカーのIC駆動保護例を踏まえて直列1kΩを入れます。
コイル式ブザーやスピーカーに交換する際はこの回路を流用しません。

PKM13EPYH4000-A0は、メーカー資料で**両面スルーホール基板への実装を避ける**よう指定されています。
購入した112978へサウンダーを直接はんだ付けせず、初期試作はブレッドボードに挿して別に固定します。
恒久実装は片面基板などメーカー条件に合う方法を選び、樹脂根元に溶けたはんだを接触させません。
[Murata資料・実装上の注意](https://akizukidenshi.com/goodsaffix/murata-piezo-speaker-tape.pdf)

## 組み立て上のルール

電源OFFで配線し、3V3とGNDの短絡・電源極性・LED極性を確認します。
電源線は購入した22AWGで短くし、ブレッドボードの電源レールが途中で切れていないか導通確認します。
SPI配線は15cm程度から始め、ソフト側のSPI速度を上げる前に動作を確認します。
ESP32アンテナの近くに電池・金属・配線束を置かず、アクリル板の端側に配置します。
SH1.0ケーブルの色順は接続の根拠にせず、LCD基板の端子名とメーカー図を使います。
